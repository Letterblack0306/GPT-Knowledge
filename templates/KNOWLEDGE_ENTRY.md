# Knowledge Entry Template

```yaml
title:
category:
sub_category:
source:
confidence: low | medium | high
verified: false
last_reviewed:
applicable_to: []
limitations: []
tags: []
```

## Problem

Describe the recurring design or engineering problem.

## Principle

State the reusable principle without tying it to one product unless the limitation is essential.

## Evidence

List authoritative references, runtime proofs, repeated project evidence, or experiments.

## Recommended pattern

Describe the preferred implementation or decision pattern.

## Avoid

Describe failure patterns, overgeneralizations, and conditions where this guidance should not be used.

## Validation

State how to prove that an implementation conforms to the knowledge entry.

## Revision notes

Record corrections, superseded assumptions, and changes in applicability.
