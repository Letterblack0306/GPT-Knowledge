# Visual Style Library

Named visual identities for motion-design projects. Use these as starting systems under [house-style.md](house-style.md), then adapt them to the actual brand and content.

| Style | Mood | Best for | Typical transition |
|---|---|---|---|
| Swiss Pulse | Clinical, precise | SaaS, data, dev tools, metrics | Cinematic zoom or SDF iris |
| Velvet Standard | Premium, timeless | Luxury, enterprise, keynotes | Cross-warp morph |
| Deconstructed | Industrial, raw | Tech launches, security, punk | Glitch or whip pan |
| Maximalist Type | Loud, kinetic | Announcements and launches | Ridged burn |
| Data Drift | Futuristic, immersive | AI, ML, speculative tech | Gravitational lens or domain warp |
| Soft Signal | Intimate, warm | Wellness and personal stories | Thermal distortion |
| Folk Frequency | Cultural, vivid | Consumer apps, food, communities | Swirl vortex or ripple waves |
| Shadow Cut | Dark, cinematic | Security, investigation, dramatic reveals | Domain warp |

## Selection rule

Match mood first, then content. Ask what the viewer should feel before selecting surface treatments.

## Style construction

A complete style should define:

- color tokens;
- typography voices;
- rounded and spacing tokens;
- motion energy, easing, duration, atmosphere, and transition;
- prose rationale explaining why the system fits;
- component rules showing how tokens combine.

The reusable pattern is:

```text
YAML tokens (what)
→ prose rationale (why)
→ components and choreography (how)
```

## Important constraint

These are starters, not fixed templates. Do not copy a style unchanged when it conflicts with the actual brand, audience, medium, or narrative.
